# 📊 E-Commerce Sales Analysis Dashboard

## 📌 Project Overview
The E-Commerce Sales Analysis Dashboard is an interactive Power BI project designed to analyze sales performance, profit, orders, customers, and product categories. It provides business insights through KPIs, charts, and filters that help identify trends and support data-driven decision-making.

---

## 🎯 Objectives
- Analyze overall sales performance.
- Track profit and order trends.
- Identify top-performing products and categories.
- Compare sales across different regions.
- Monitor business KPIs using interactive dashboards.

---

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- CSV Dataset

---

## 📈 Dashboard Features
- 💰 Total Sales KPI
- 📦 Total Orders KPI
- 📊 Total Profit KPI
- 📅 Monthly Sales Trend
- 🛒 Sales by Product Category
- 🏆 Top 5 Products by Sales
- 🌍 Sales by Region
- 📈 Profit Analysis
- 🎛️ Interactive Slicers (Month, Quarter, Year, Category)

---

## 📂 Dataset
The project uses e-commerce sales data containing information such as:
- Order ID
- Order Date
- Customer Name
- Product Category
- Product
- Sales Amount
- Profit
- Quantity
- Region

---

## 📊 Key Insights
- Identified top-selling products.
- Compared sales performance across regions.
- Analyzed monthly sales trends.
- Tracked profit contribution by category.
- Monitored overall business performance using KPIs.
